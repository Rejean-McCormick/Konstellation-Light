# Konstellation-Light — V19 : exploration visuelle et navigation complète

## But

Remplacer la surpopulation des cercles, les libellés invisibles au-delà de dix éléments et les points de deuxième niveau ambigus par une exploration progressive et lisible. Aucune modification des 126 Kristals publics n'est effectuée.

## Parcours public

1. **Découverte** : au chargement d'un Kristal de connaissances, des points d'entrée nommés et réellement connectés sont proposés, sans affirmer qu'ils sont plus importants scientifiquement.
2. **Proximité** : carte à deux colonnes, huit voisins maximum, cartes avec espaces de texte réservés, libellés en une à trois lignes, lignes reliées uniquement aux relations présentes. Les autres voisins restent accessibles avec « Autres connexions » ; leur identité n'est jamais inventée.
3. **Compréhension** : fiche de notion enrichie des liens entrants/sortants, définition réelle si disponible, conditions de provenance et accès aux documents sources. Les longues étiquettes restent intégralement accessibles dans les boutons de navigation et dans la fiche, même si la carte applique une ellipse.
4. **Repérage** : fil de navigation, retour, départ, recherche, pagination et liens partageables. La pagination figure dans `pg` de l'URL, sans changer les données.
5. **Mobile** : navigation tactile par cartes reliées verticalement, titres complets, sans survol obligatoire. La carte SVG demeure disponible sur les vues plus larges, avec défilement horizontal si nécessaire pour conserver une taille de police minimale.
6. **Documents** : 49 Kristals sont présentés par leur véritable classement documentaire. Leur carte est visuelle, mais ses lignes ne sont pas des assertions sémantiques. Le lecteur propose une carte de catégorie, une sélection de document et des liens épinglés lorsqu'ils existent.

## Fidélité / sécurité

- Aucun lien ajouté, aucune relation traduite par supposition.
- Une relation sans libellé public porte « Lien déclaré ».
- Les numéros de notions anonymes ne sont pas des noms.
- Les descriptions techniques sensibles restent filtrées par le lecteur existant.
- La provenance et la révision sont préservées ; aucun contenu de source n'est modifié.
- Les mécanismes C4 et GitHub Pages restent distincts : une bêta n'est pas une certification C1-C4.
- Le paquet V19 n'exécute aucune publication ni commande Git.

## Contrôles

- Suite Node ciblée : `node --test tests/light-*.test.mjs` ; 45 tests réussis dans la copie de référence.
- Inventaire des 126 packs, 77 graphes de connaissances, 49 cartes documentaires.
- Contrôles géométriques des étiquettes et pagination par page ; étiquettes visibles sur toutes les cartes, sans supprimer les noms lorsque l'utilisateur augmente le budget.
- Audit V19 Windows : `py -3.12 AUDIT_V19.py --check`, puis `LANCER-AUDIT-V19.cmd` ; vérification CSS, ressources et captures desktop/mobile.

## Limites à valider sur Windows avant Git Sync

La navigation réelle et l'absence de collision **dans Chromium** ne sont pas attestées par les tests de code. Cet environnement a retourné `net::ERR_BLOCKED_BY_ADMINISTRATOR` lors de l'ouverture du serveur local. La validation navigateur V19 doit être effectuée avec l'auditeur Windows joint, puis examinée avant la publication HTTPS.
